# Stargazer Cat production-size sprites

Six 384×384 transparent PNGs: `idle`, `activity`, `focus`, `complete`, `rest`,
and `guide`. Source art and generation notes are in
`design/stargazer-source/`. Bounds for home-card rendering live in
`lib/widgets/ds/animated_cat.dart`.

The three matching decorations are `assets/decorations/stargazer-telescope.png`,
`stargazer-meteor.png`, and `stargazer-celestial-globe.png`.
