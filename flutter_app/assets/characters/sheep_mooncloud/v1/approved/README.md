# 달구름 양 v1

앱에 포함하는 384×384 투명 PNG 여섯 장: `idle`, `activity`, `focus`, `complete`, `rest`, `guide`.

사용자가 준 구름·달 양 시안을 바탕으로 포즈와 장식 세 종, 파스텔 하늘 배경을 만들었다. 원본 시트는 `design/mooncloud-sheep/`에 보관한다. `python3 tool/prepare_mooncloud_sheep_assets.py`로 앱용 PNG를 다시 생성할 수 있다.

포즈 순서: 대기, 걷기, 잠자리 책 읽기, 완료 축하, 구름에서 자기, 안내하기.
