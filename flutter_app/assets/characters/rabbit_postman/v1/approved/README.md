# 우편배달부 토끼

첨부 콘셉트 이미지의 크림색 토끼, 코랄 스카프, 갈색 우편 가방을 기준으로 만든 6포즈입니다.
모든 PNG는 384×384 투명 캔버스입니다.

| 파일 | 동작 |
| --- | --- |
| `idle.png` | 앉아서 대기 |
| `activity.png` | 편지를 들고 달리기 |
| `focus.png` | 편지 쓰기 |
| `complete.png` | 배달을 마치고 편지 들어 올리기 |
| `rest.png` | 가방 곁에서 잠들기 |
| `guide.png` | 편지를 들고 오른쪽 안내하기 |

원본 시트와 추출 스크립트는 `flutter_app/design/postman-rabbit/`와
`flutter_app/tool/prepare_postman_rabbit_assets.py`에 있습니다.
