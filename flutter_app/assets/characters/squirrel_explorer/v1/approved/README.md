# 탐험가 다람쥐 v1

앱에 포함하는 384×384 투명 PNG 여섯 장: `idle`, `activity`, `focus`, `complete`, `rest`, `guide`.

첨부된 탐험가 다람쥐 시안을 바탕으로 여섯 포즈와 장식 3종, 숲 배경을 생성했다. 원본 시트는 `design/explorer-squirrel/`에 보관한다. `python3 tool/prepare_explorer_squirrel_assets.py`로 앱용 파일을 다시 뽑을 수 있다.

포즈 순서: 대기, 지도와 함께 걷기, 지도를 살펴보며 집중하기, 도토리를 들고 기뻐하기, 꼬리 안에서 자기, 길을 가리키기.
