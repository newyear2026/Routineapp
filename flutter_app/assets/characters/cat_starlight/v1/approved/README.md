# 고양이 별빛 대표 자세 6종

앱 적용 대상으로 검수한 투명 PNG만 모은 폴더다. 모든 이미지는 1254×1254 RGBA이며 투명 알파 채널을 포함한다.

| 상태 | 파일 | 동작 | 추천 위치 |
| --- | --- | --- | --- |
| 대기 | `idle.png` | 정면으로 편안하게 앉기 | 홈 기본 상태, 빈 상태 |
| 활동 | `activity.png` | 오른쪽으로 걷기 | 현재 루틴, 진행 화면 |
| 집중 | `focus.png` | 노트와 연필 들기 | 루틴 추가·수정, 집중 루틴 |
| 완료 | `complete.png` | 두 앞발만 보이는 상반신 응원 자세 | 완료 피드백, 진행 결과 |
| 휴식 | `rest.png` | 몸을 말고 잠들기 | 휴식·취침 루틴, 대기 안내 |
| 안내 | `guide.png` | 한 앞발을 들어 안내하기 | 온보딩, 권한·충돌 안내 |

## 표시 기준

- `BoxFit.contain`과 `Alignment.bottomCenter`를 사용한다.
- 픽셀 가장자리가 흐려지지 않도록 원본 비율을 유지한다.
- 화면 상단 장식은 96–120dp, 카드 안 캐릭터는 56–80dp를 기준으로 시작한다.
- 서로 다른 자세를 같은 자리에 교체할 때는 상위 `placement.json`의 보정값을 적용한다.
- 그림자와 별 장식은 PNG에 합치지 않고 화면 레이어에서 추가한다.

`cheer-star-preview.png`는 배경이 포함된 시안이므로 이 폴더에 포함하지 않는다.
