# 캐릭터 동작 연결

공통 컴포넌트: lib/widgets/ds/animated_cat.dart.
승인 PNG를 바꾸지 않고 5–7개 변형 키프레임으로 동작을 렌더링한다.
새로 그린 연속 PNG 스프라이트는 아니다.

| 상태 | 키프레임 동작 | 홈 연결 |
| --- | --- | --- |
| idle | 약한 호흡 | 현재 루틴 없음·스킵 |
| activity | 세 번 들썩임 | 일반 진행 루틴 |
| focus | 가벼운 끄덕임 | 책·컴퓨터·연필 아이콘 |
| complete | 준비·기쁨·복귀 | 현재 루틴 완료 |
| rest | 느린 호흡 | 미루기·휴식 아이콘 |
| guide | 가벼운 인사 | 공통 컴포넌트에서 사용 가능 |

800ms 동작 후 쉬며 4초마다 다시 재생한다.
동작 줄이기·비활성 탭·백그라운드에서는 중단하고 타이머를 해제한다.
고정 박스 안에서 PNG 불투명 경계를 하단 중앙에 정렬한다.
전환 중 기존 디코딩 이미지를 유지해 빈 프레임을 방지한다.
홈은 현재 슬롯의 로그 상태와 `iconId`로 포즈를 고른다. 진행·루틴·설정 탭은 메뉴마다 고정 포즈다.
다리 걷기·눈 깜박임·손 흔들기처럼 신체 일부가 변하는 연속 그림은 별도 제작이 필요하다.
