# 캐릭터 팩별 Medium 위젯 색상 시안

기존 Medium 위젯을 바탕으로 별빛 고양이·푸들 정원의 색을 비교한 이미지 시안이다.
현재 앱과 시스템 위젯에 팩별 배경색 전환은 구현되지 않았다.

- `subtle-pack-tint.png`: 기존 위젯의 정보 배치를 유지하고 배경·강조색을 은은하게 변경
- `full-pack-palette.png`: 카드 전체에 팩 팔레트를 넓게 반영
- `soft-pack-gradient.png`: 팩별 배경 그라데이션과 작은 픽셀 장식 적용

각 시안의 원형 시간표 구간색은 캐릭터 팩과 별개인 루틴 색을 나타낸다.
