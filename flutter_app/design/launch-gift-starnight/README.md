# 출시 기념 한정 팩 «별밤 고양이» 시안

출시 기간 안에 처음 앱을 연 사람에게 주는 한정 팩의 이미지 시안이다.
앱에는 아직 구현되지 않았다.

- `loopet-launch-gift-starnight-ko.png`: 전체 시트 (비교 · 6포즈 · 장식 · 팩 색 · 위젯 · 선물 도착 화면 · 스토어 문구)
- `widget-medium-starnight.png`: Medium 위젯 단독 시안
- `poses/`: 6포즈 시안 PNG (384px, 투명)

포즈 그림은 기존 별빛 고양이 승인본 위에 망토 · 초승달 배지 · 고깔모자를 코드로
얹은 것이라 선이 딱딱하다. 방향이 확정되면 원본과 같은 방식으로 다시 그린다.
