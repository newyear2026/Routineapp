# 캐릭터 팩별 홈 배경색 시안

기존 8개 캐릭터 팩과 홈 카드 구성을 참고해 내장 Image Gen으로 만든 비교 시안이다. 앱에는 아직 적용하지 않았다.

| 이미지 | 방향 |
| --- | --- |
| `01-quiet-pastel.png` | 장식 없이 팩별 밝은 단색 배경 |
| `02-soft-scene-gradient.png` | 팩별 그라데이션과 작은 픽셀 장면 |
| `03-bold-two-tone.png` | 선명한 상단 색과 밝은 하단 색을 나눈 투톤 배경 |

각 시안은 왼쪽 위부터 별빛 고양이, 푸들 정원, 유성 관측 고양이, 우편배달부 토끼, 탐험가 다람쥐, 달구름 양, 랫서팬더 찻집, 햇살 해달 순서다. 생성 시에는 기존 캐릭터의 외형과 홈 카드의 픽셀 테두리를 유지하고, 팩별 배경색만 비교되도록 요청했다.

단색안 기준 색상: 별빛 `#EAE4FF`, 푸들 `#D9F4E5`, 유성 `#DCE8FF`, 토끼 `#FFE5D7`, 다람쥐 `#E5EECF`, 양 `#E8E9FF`, 랫서팬더 `#F9E2C9`, 해달 `#D7F2F1`.

## 선택한 방향

사용자가 `02-soft-scene-gradient.png`를 선택했다. 이후 팩별 홈 배경 작업의 기준 이미지로 사용한다.

| 팩 | 배경 인상 | 작은 장면 요소 |
| --- | --- | --- |
| 별빛 고양이 | 라벤더에서 복숭아빛으로 가는 저녁 하늘 | 별과 초승달 |
| 푸들 정원 | 민트에서 햇살빛으로 가는 정원 | 잎과 데이지 |
| 유성 관측 고양이 | 코발트에서 남색으로 가는 밤하늘 | 유성과 별자리 |
| 우편배달부 토끼 | 코랄에서 크림빛으로 가는 새벽 | 편지와 구름 |
| 탐험가 다람쥐 | 올리브에서 세이지로 가는 숲 | 잎과 나무 |
| 달구름 양 | 연보라에서 라일락으로 가는 구름 하늘 | 초승달과 구름 |
| 랫서팬더 찻집 | 테라코타에서 따뜻한 크림빛으로 가는 실내 | 찻잔 김과 창가 |
| 햇살 해달 | 터키색에서 옅은 모래빛으로 가는 바다 | 물결과 갈매기 |

홈 카드의 글씨 뒤에는 밝은 면을 남기고, 풍경 장식은 카드 오른쪽과 상단에 더 많이 둔다. 앱에는 이미 팩별 시간대 풍경과 카드 그림이 있으므로 기존 에셋을 기준으로 색감과 대비를 맞춘다. 이 시안 그림 자체를 앱 배경 에셋으로 사용하지 않는다. 그림 안에 UI 글자와 캐릭터가 포함되어 있기 때문이다.
