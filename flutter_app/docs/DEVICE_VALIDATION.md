# 별빛 테마 기기 검증

검증일: 2026-09-10

## 자동 검증 범위

- 320×568, 390×844, 844×390, 768×1024 논리 픽셀에서 글자 1배·2배.
- 홈, 진행, 루틴, 설정, 추가, 수정, 온보딩, 위젯 미리보기의 최초 배치와 세로 스크롤.
- 360×640에서 한국어·영어·스페인어와 글자 1배·1.3배.
- 기존 시간·요일 선택, 저장, 충돌 경고 취소/저장, 삭제 취소/확인 테스트.
- 고양이 6종의 고정 영역, 모션 감소, TickerMode 비활성, 백그라운드 중지와 재개.

## 발견 및 수정

- 320px·2배 글자에서 시간표 중앙 Column이 4.3px 넘침: 중앙 원의 별도 영역에서
  비율을 유지하며 축소한다. 주변 본문 글자 확대는 유지한다.
- 스페인어 위젯의 다음 일정 안내가 1.5px 넘침: 안내 문구에 유연한 폭과 말줄임을 적용한다.

## 실행 확인과 한계

Android 16 API 36 arm64 에뮬레이터에서 debug 앱 빌드·실행 및 설정 화면 캡처를 확인했다.
실물 Android/iOS 기기는 연결되어 있지 않았다.

`adb dumpsys gfxinfo`의 표본은 3프레임뿐이며 Flutter Surface 렌더링 성능을
대표하지 않는다. 이 수치로 FPS나 부드러움을 판정하지 않는다.
실물 기기 profile 모드의 Flutter 프레임 타이밍·메모리·발열 측정은 남아 있다.
자동 테스트의 모션 중지 검증은 불필요한 프레임 요청을 확인하며 실제 GPU 성능 측정은 아니다.
